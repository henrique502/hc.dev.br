# Product

Personal website / link-in-bio page for Henrique Schmidt (@henrique502), hosted at hc.dev.br.

- Simple single-page site displaying a profile photo (Gravatar), name, and social links (GitHub, LinkedIn)
- Includes a 404 page with a home link
- Language: Brazilian Portuguese
- Dark mode support via `prefers-color-scheme` media query
- Robots meta set to "none" (not indexed by search engines)
